什么是 BIP39？

BIP39（Bitcoin Improvement Proposal 39）定义了将随机熵编码为一组助记词的标准。12 个单词 = 128-bit 安全强度，24 个单词 = 256-bit。每个单词来自 2048 个词的标准化词表。

双重熵源混合

本工具同时采集两路随机源：系统 CSPRNG（密码学安全伪随机数）+ 你的物理动作（鼠标/触摸坐标+时间噪声）。两者经 SHA-256 混合，即使其中一路被攻破，另一路仍能保证安全。

CSPRNG 是什么？

密码学安全伪随机数生成器（CSPRNG）利用操作系统的熵池产生不可预测的随机数。浏览器通过 Web Crypto API (getRandomValues) 访问，其安全强度经过严格的密码学验证。
